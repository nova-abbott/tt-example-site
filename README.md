# Translation Corpus Explorer (Example)

An example static website for the 2026R1 final project. It shows search, filters, two linked charts, and a learning-report page.

Sample data: 60 English–Chinese subtitle pairs from OpenSubtitles (see about.html). Sample only; do not reuse the data without checking its terms of use.
