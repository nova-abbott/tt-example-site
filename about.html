About this site

This is an example site for the 2026R1 final project. It shows the structure students can adapt: search and filters, two charts that respond to filters, and a learning report.

Data source

The sample data (data/sample.json) contains 60 English–Chinese subtitle pairs from the OpenSubtitles corpus (version 2024, English–Simplified Chinese). Entries were selected at random and filtered to remove profanity. Chinese text is in Simplified characters because that is how the source corpus is written.

Source: opensubtitles.org. Please cite the corpus you use in your own project. Other corpora: OPUS (opus.nlpl.eu).

Human check

All sample entries are marked human_checked: "no". Some alignments are imperfect. For example, one English line may be paired with a Chinese line that does not match. Your own project should mark only entries you have checked yourself.

AI use declaration (example)

This example site was built with an AI agent. The agent wrote the HTML, CSS, and JavaScript. The sample data was extracted from the local corpus files with a script. The developer checked the code by running it locally and by viewing the published pages.

Copyright and privacy

The sample uses short subtitle lines for demonstration only. Do not publish full copyrighted texts or personal information on your own site.
